## 🔥 The Experience

<div align="center">

> ### 🎧 *GeerVibes isn't just a music player — it's a **cyberpunk audio sanctuary**.*

</div>

## 🚀 Getting Started

<div align="center">

![](https://img.shields.io/badge/Step_1-Clone-00FFFF?style=for-the-badge&labelColor=001a1a)
![](https://img.shields.io/badge/Step_2-Navigate-A78BFA?style=for-the-badge&labelColor=100a2e)
![](https://img.shields.io/badge/Step_3-Open_%26_Play-10B981?style=for-the-badge&labelColor=002d0d)

</div>

```bash
# ① Clone the repository
git clone https://github.com/geershatisaxena/GeerVibes.git

# ② Navigate into the project
cd GeerVibes

# ③ Open in your browser — no build step needed
open index.html
```

<div align="center">

| ✅ 3 commands | ✅ 0 dependencies | ✅ 0 build steps | ✅ instant audio |
|:---:|:---:|:---:|:---:|
| ![](https://img.shields.io/badge/git_clone-00FFFF?style=flat-square) | ![](https://img.shields.io/badge/npm_install-NONE-FF6B6B?style=flat-square) | ![](https://img.shields.io/badge/webpack-NONE-FF6B6B?style=flat-square) | ![](https://img.shields.io/badge/%F0%9F%94%8A-PLAY-10B981?style=flat-square) |

> **⚡ No `npm install`. No `node_modules`. No waiting. Just open and play.**

## 🎨 Design Philosophy

GeerVibes is built on **three uncompromising principles**:

<div align="center">

| Principle | What It Means | Badge |
|:---:|:---|:---:|
| 💾 **Zero Dependencies** | No frameworks, no CDN, no liability — pure vanilla power | ![](https://img.shields.io/badge/ZERO_DEPS-00FFFF?style=for-the-badge&labelColor=001a1a) |
| 🌱 **Progressive Enhancement** | Works on any modern browser, degrades gracefully | ![](https://img.shields.io/badge/ALL_BROWSERS-10B981?style=for-the-badge&labelColor=002d0d) |
| ⚡ **Performance First** | Lazy loading, async I/O, and `requestAnimationFrame` for every animation | ![](https://img.shields.io/badge/60_FPS-F59E0B?style=for-the-badge&labelColor=2d1500) |

</div>
