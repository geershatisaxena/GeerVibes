## 🔥 The Experience

<div align="center">

> **320+ tracks** · **Zero latency** · **Neon aesthetics** · **Full keyboard command**

## 🎛️ Feature Matrix

<div align="center">

| Module | Capability |
|:------:|:-----------|
| 🎵 **AUDIO ENGINE** | Web Audio API masterpiece — play, pause, seek, skip, loop, shuffle with real-time metadata |
| 📊 **WAVE VISUALIZER** | 20-bar neon spectrum analyser — *pulses to your actual audio frequency data* |
| 🔁 **SMART QUEUE** | Fisher-Yates shuffle + 3 repeat modes (off / single / all) |
| 🔍 **LIVE SEARCH** | Instant filtering by track title or artist — no debounce lag, just speed |
| ❤️ **FAVORITES** | One-click save → persistent localStorage → filter queue to show only loved tracks |
| 🔊 **VOLUME DOMINATION** | Smooth logarithmic slider + mute toggle + keyboard shortcuts (`+` / `-` / `M`) |
| 📱 **MOBILE MINI-PLAYER** | Sticky bottom bar on mobile — essential controls, one-thumb operation |
| 🌙 **DUAL THEMES** | Cyberpunk Neon (default) ↔ Holographic Day Mode — persistent across sessions |
| ⏳ **LAZY DURATION LOAD** | Shimmer placeholders → async duration fetch → no UI blocking |
| 💾 **ZERO EXTERNAL CALLS** | System-native fonts only — no Google Fonts, no CDN, no tracking |
| 🎨 **CYBERPUNK DNA** | Neon glows, glassmorphism, CSS grid scanlines, clip-path geometry, reactive hover states |
| ⌨️ **KEYBOARD GOD MODE** | `Space` · `←` / `→` (seek ±10s) · `↑` / `↓` (volume) · `S` (shuffle) · `L` (loop) · `F` (favourite) |

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/geershatisaxena/GeerVibes.git

# Navigate into the project
cd GeerVibes

# Open in your browser — no build step needed
open index.html
```

> No `npm install`. No `node_modules`. No waiting. Just open and play.

<details>
<summary><strong>🌐 Or run it via a local server (recommended for some browsers)</strong></summary>

```bash
# Using Python
python3 -m http.server 8000

# Using Node
npx serve .
```

Then visit `http://localhost:8000` in your browser.
</details>

## ⌨️ Keyboard Shortcuts

| Key | Action |
|:---:|:-------|
| `Space` | Play / Pause |
| `←` `→` | Seek ±10 seconds |
| `↑` `↓` | Volume up / down |
| `+` `-` | Fine volume control |
| `M` | Mute toggle |
| `S` | Shuffle |
| `L` | Loop mode |
| `F` | Favourite current track |

## 🎨 Design Philosophy

GeerVibes is built on three principles:

- **Zero dependencies** — no frameworks, no CDN, no liability
- **Progressive enhancement** — works on any modern browser, degrades gracefully
- **Performance first** — lazy loading, async I/O, and `requestAnimationFrame` for every animation
