```bash
# ① Clone the repository
git clone https://github.com/geershatisaxena/GeerVibes.git

# ② Navigate into the project
cd GeerVibes

# ③ Open in your browser — no build step needed
open index.html
```

## 🎨 Design Philosophy

GeerVibes is built on **three uncompromising principles**:

<div align="center">

| Principle | What It Means | Badge |
|:---:|:---|:---:|
| 💾 **Zero Dependencies** | No frameworks, no CDN, no liability — pure vanilla power | ![](https://img.shields.io/badge/ZERO_DEPS-FF0055?style=for-the-badge&labelColor=1a0010) |
| 🌱 **Progressive Enhancement** | Works on any modern browser, degrades gracefully | ![](https://img.shields.io/badge/ALL_BROWSERS-00FF88?style=for-the-badge&labelColor=002d00) |
| ⚡ **Performance First** | Lazy loading, async I/O, and `requestAnimationFrame` for every animation | ![](https://img.shields.io/badge/60_FPS-0088FF?style=for-the-badge&labelColor=001a2d) |

</div>
