# ① Clone the repository
git clone https://github.com/geershatisaxena/GeerVibes.git

# ② Navigate into the project

open index.html

## 🎨 Design Philosophy

GeerVibes is built on **three uncompromising principles**:

<div align="center">

<table>
<tr>
<td align="center" width="220">
<img src="https://img.shields.io/badge/💾-ZERO_DEPENDENCIES-FF3CAC?style=for-the-badge&labelColor=1a0013"/>

No frameworks, no CDN, no liability.<br/>Pure vanilla power from first principles.
</td>
<td align="center" width="220">
