## 🔥 The Experience

<div align="center">

> ### 🎧 *GeerVibes isn't just a music player — it's a **cyberpunk audio sanctuary**.*

</div>

Every pixel glows, every transition hums, and the sound engine punches way above its weight class. **No backend. No databases.** Just you, your library, and the purest vanilla JavaScript your browser can handle.

```bash
# ① Clone the repository
git clone https://github.com/geershatisaxena/GeerVibes.git

# ② Navigate into the project
cd GeerVibes

# ③ Open in your browser — no build step needed
open index.html
```

## 🎨 Design Philosophy

GeerVibes is built on **three uncompromising principles**:

<div align="center">

| Principle | What It Means | Badge |
|:---:|:---|:---:|
| 💾 **Zero Dependencies** | No frameworks, no CDN, no liability — pure vanilla power | ![](https://img.shields.io/badge/ZERO_DEPS-ff0000?style=for-the-badge&labelColor=1a0000) |
| 🌱 **Progressive Enhancement** | Works on any modern browser, degrades gracefully | ![](https://img.shields.io/badge/ALL_BROWSERS-00ff44?style=for-the-badge&labelColor=002d00) |
| ⚡ **Performance First** | Lazy loading, async I/O, and `requestAnimationFrame` for every animation | ![](https://img.shields.io/badge/60_FPS-0088ff?style=for-the-badge&labelColor=001a2d) |

</div>
