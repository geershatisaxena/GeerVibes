## 🔥 The Experience

<div align="center">

> 🎧 **GeerVibes isn't just a music player — it's a cyberpunk audio sanctuary.**

</div>

Every pixel glows, every transition hums, and the sound engine punches way above its weight class. **No backend. No databases.** Just you, your library, and the purest vanilla JavaScript your browser can handle.

<div align="center">

```
┌─────────────────────────────────────────────────────────────────┐
│  🌊  WAVE VISUALIZER  ·  🎶  WEB AUDIO API  ·  💾  ZERO DEPS   │
│  🌙  DUAL THEMES     ·  📱  MOBILE READY   ·  ⌨️  KEYBOARD GOD │
└─────────────────────────────────────────────────────────────────┘
```

</div>

## 🚀 Getting Started

> **⚡ No `npm install`. No `node_modules`. No waiting. Just open and play.**

```bash
# ① Clone the repository
git clone https://github.com/geershatisaxena/GeerVibes.git

# ② Navigate into the project
cd GeerVibes

# ③ Open in your browser — no build step needed
open index.html
```

<div align="center">

```
  ✅  3 commands   ✅  0 dependencies   ✅  instant audio
```

</div>

## 🎨 Design Philosophy

GeerVibes is built on **three uncompromising principles**:

<div align="center">

| 🏛️ Principle | 💡 What It Means |
|:---:|:---|
| **Zero Dependencies** | No frameworks, no CDN, no liability — pure vanilla power |
| **Progressive Enhancement** | Works on any modern browser, degrades gracefully |
| **Performance First** | Lazy loading, async I/O, and `requestAnimationFrame` for every animation |

</div>
